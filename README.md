# 🏥 Hospital Data SQL Analysis

## 📌 Project Overview

This project focuses on analyzing hospital data using SQL and PostgreSQL.

The project explores hospital operations, patient counts, doctor availability, departments, hospital stays, and medical expenses through a set of SQL queries.

---

## 🛠️ Tools & Technologies

- PostgreSQL
- SQL
- pgAdmin 4

---

## 📂 Dataset

The dataset contains hospital-related information such as:

- Hospital Name
- Location
- Department
- Doctors Count
- Patients Count
- Admission Date
- Discharge Date
- Medical Expenses

Satish Dhawale Sir

## 🔍 Analysis Performed

The project answers the following questions:

1. Total number of patients across all hospitals
2. Average number of doctors per hospital
3. Top 3 departments with the highest number of patients
4. Hospital with the maximum medical expenses
5. Daily average medical expenses for each hospital
6. Longest hospital stay
7. Total patients treated per city
8. Average length of stay per department
9. Department with the lowest number of patients
10. Monthly medical expenses report

## 💡 Key Analysis Areas

### 🧑‍⚕️ Patient Analysis

Analyzed the total number of patients and compared patient counts across different departments and locations.

### 🏥 Hospital Analysis

Analyzed hospitals based on doctor availability and medical expenses.

### 📅 Stay Duration Analysis

Calculated the longest hospital stay and the average length of stay for different departments.

### 💰 Medical Expense Analysis

Analyzed daily and monthly medical expenses to understand expense patterns across the dataset.
